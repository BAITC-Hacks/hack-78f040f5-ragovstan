# Defect Detector

Простой классификатор изображения: определяет, есть ли дефект.

## Установка

```bash
pip install Pillow
```

## Запуск

```bash
python detector.py ok.png
python detector.py defect.png
```

## Как работает

Скрипт открывает изображение и считает долю красных пикселей.

Если красного цвета больше 30% кадра, результат:
`DEFECT`

Иначе:
`OK`

## Результат

Для `ok.png` программа выводит `OK`.

Для `defect.png` программа выводит `DEFECT`.

Это демонстрационный вариант без ML-модели.
